# Creator（内容创作者）

## 识别关键词
blog, newsletter, podcast, creator, content, subscriber, article, post, RSS, writing, publish, author

## 核心骨架
- 内容列表 + 详情页（文章/播客/视频）
- 订阅/关注机制
- 分类/标签体系
- 创作者个人品牌展示

## 典型可定制点

| 可定制点 | 粒度 | 说明 |
|--------|------|------|
| 内容类型 | 数据模型 | 长文、短动态、播客、视频、Newsletter |
| 变现方式 | 功能模块 | 付费订阅、打赏、会员专属、广告位 |
| 互动功能 | 组件级 | 评论、点赞、收藏、分享、书签 |
| 搜索/发现 | 功能模块 | 全文搜索、标签云、系列/专栏 |
| RSS/订阅 | 功能模块 | RSS feed、邮件订阅、推送通知 |
| 阅读体验 | 视觉层 | 暗黑模式、字号调节、阅读进度条、目录 |
| SEO 增强 | 全局 | 结构化数据、sitemap、OG tags |

## 设计推断侧重
- 内容调性 → 排版风格（技术偏等宽紧凑，文学偏衬线宽松，新闻偏高密度）
- 内容长度 → 阅读体验（长文需目录+进度条，短文偏卡片流）
- 更新频率 → 首页布局（日更用时间线，周更用卡片，精品用大图）
- 创作者人设 → 视觉个性化程度

## 常见陷阱
- Markdown/MDX 渲染中的 XSS 防御
- 代码块高亮的包体积（按需加载语言包）
- 图片 CDN 和响应式图片
- 无限滚动列表的 SEO 影响（需要分页替代方案）
- 邮件订阅表单的垃圾防护

# Travel（旅游/出行）

## 识别关键词
travel, trip, destination, itinerary, hotel, flight, tour, guide, attraction, map, explore

## 核心骨架
- 目的地展示（图片 + 介绍 + 推荐）
- 行程规划/攻略（时间线、地图标注）
- 搜索/预订入口（酒店、机票、门票）
- 游记/用户分享

## 典型可定制点

| 可定制点 | 粒度 | 说明 |
|--------|------|------|
| 地图集成 | 功能模块 | 目的地标注、路线规划、热点聚合 |
| 行程编辑 | 功能模块 | 拖拽排序、时间分配、备注 |
| 天气/实况 | 组件级 | 实时天气、最佳旅行季节、穿搭建议 |
| 费用估算 | 功能模块 | 预算规划、实际花销记录、汇率 |
| 社区分享 | 功能模块 | 游记发布、照片墙、评分 |
| 多语言 | 全局配置 | 目的地名称多语言、货币切换 |
| 离线支持 | 功能模块 | 行程离线查看、离线地图 |

## 设计推断侧重
- 旅行类型 → 视觉风格（背包客偏冒险粗犷，度假偏优雅舒适，商务偏简洁高效）
- 内容重心 → 布局（攻略重文字排版，目的地重大图沉浸，预订重表单效率）
- 目标市场 → 配色和意象（东南亚偏热带鲜艳，北欧偏冷调极简）
- 用户阶段 → 功能优先级（灵感阶段重发现，规划阶段重工具）

## 常见陷阱
- 大量目的地图片的加载优化（CDN + 压缩 + 懒加载）
- 地图 SDK 包体积对首屏的影响
- 多时区的日期展示（出发地时间 vs 目的地时间）
- 行程拖拽排序在移动端的交互
- 货币汇率的实时性与缓存策略

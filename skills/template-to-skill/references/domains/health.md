# Health（健康/医疗）

## 识别关键词
health, fitness, wellness, medical, doctor, appointment, tracker, workout, nutrition, BMI, vital

## 核心骨架
- 健康数据仪表盘（指标卡片 + 趋势图）
- 记录/打卡功能（饮食、运动、睡眠、体重）
- 服务预约（问诊、体检、课程）
- 知识/建议内容（文章、视频、AI 建议）

## 典型可定制点

| 可定制点 | 粒度 | 说明 |
|--------|------|------|
| 数据类型 | 数据模型 | 体重、血压、心率、步数、饮水、睡眠 |
| 图表类型 | 组件级 | 趋势线、日历热力图、对比图、目标进度环 |
| 运动模块 | 功能模块 | 运动计划、训练动作库、计时器 |
| 饮食记录 | 功能模块 | 食物库、营养计算、餐食拍照 |
| 社区激励 | 功能模块 | 挑战赛、好友 PK、成就徽章 |
| 专业咨询 | 功能模块 | 在线问诊、报告解读、处方 |
| 设备集成 | 功能模块 | 手环/手表数据同步、Apple Health |

## 设计推断侧重
- 健康方向 → 配色（健身偏活力橙绿，医疗偏冷静蓝白，冥想偏柔和紫粉）
- 数据密度 → 仪表盘复杂度（轻量追踪 vs 专业监测）
- 用户动机 → 激励设计（游戏化 vs 专业数据）
- 年龄段 → 字号和交互方式（老年偏大字简单，年轻偏紧凑丰富）

## 常见陷阱
- 图表在移动端的触摸交互（缩放、滑动选日期）
- 健康数据的单位换算（公斤/磅、厘米/英尺）
- 日期选择器的范围限制和快捷选项
- 目标进度的边界情况（超过 100% 怎么展示）
- 隐私敏感数据的展示控制

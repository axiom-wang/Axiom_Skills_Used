# Booking（预约/预订系统）

## 识别关键词
booking, reservation, schedule, appointment, calendar, availability, slot, check-in, check-out, guest

## 核心骨架
- 可用时间/房态展示（日历或时间线）
- 预订流程（选择 → 填信息 → 确认 → 支付）
- 预订管理（我的预订列表、修改、取消）
- 服务/房型/项目详情页

## 典型可定制点

| 可定制点 | 粒度 | 说明 |
|--------|------|------|
| 日历视图 | 组件级 | 月/周/日视图、可用性热力图 |
| 多资源管理 | 数据模型 | 多房型、多服务人员、多场地 |
| 动态定价 | 业务逻辑 | 旺季加价、早鸟优惠、连住折扣 |
| 提醒通知 | 功能模块 | 预约前提醒、确认邮件、评价邀请 |
| 团体预订 | 功能模块 | 多人预约、团购、包场 |
| 评价系统 | 组件级 | 服务评分、文字评价、标签评价 |
| 地图集成 | 功能模块 | 位置展示、导航、附近推荐 |

## 设计推断侧重
- 预订频率 → 流程简化程度（高频一键预约，低频详尽引导）
- 服务类型 → 日历粒度（酒店按天，理发按 30 分钟，餐厅按时段）
- 价格敏感度 → 价格展示方式（酒店总价，餐厅人均）
- 决策因素 → 信息层级（酒店重图片位置，医疗重资质评价）

## 常见陷阱
- 时区处理（跨时区预订的显示）
- 并发预约冲突（同一时段被多人选中）
- 日历组件的性能（大量日期渲染）
- 表单步骤之间的状态保持（返回上一步不丢失）
- 取消/退款策略的 UI 展示

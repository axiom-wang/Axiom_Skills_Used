# Food（餐饮/美食）

## 识别关键词
food, restaurant, menu, recipe, delivery, order, cuisine, chef, meal, ingredient, reservation, takeout

## 核心骨架
- 菜单/食谱展示（分类 + 图片 + 价格/配料）
- 下单/外卖流程 或 食谱详情页
- 餐厅/品牌介绍
- 位置/配送范围

## 典型可定制点

| 可定制点 | 粒度 | 说明 |
|--------|------|------|
| 菜单分类 | 数据模型 | 按菜系、按食材、按饮食偏好（素食/清真/无麸质） |
| 在线点餐 | 功能模块 | 加购物车、规格选择、备注、结算 |
| 食谱步骤 | 组件级 | 分步骤展示、计时器、用量换算 |
| 评价系统 | 组件级 | 菜品评分、图片评价、口味标签 |
| 外卖追踪 | 功能模块 | 订单状态、配送进度、预计时间 |
| 营养信息 | 数据模型 | 卡路里、蛋白质、过敏原标注 |
| 预约订座 | 功能模块 | 时段选择、人数、特殊需求 |

## 设计推断侧重
- 餐饮类型 → 视觉风格（高端餐厅偏暗底金字，快餐偏明亮高饱和）
- 核心功能 → 布局重心（外卖重效率列表，食谱重步骤展示，餐厅重氛围图片）
- 食物摄影 → 图片规格（全幅大图 vs 方形卡片）
- 地域文化 → 装饰元素和字体（日料偏简约，火锅偏热闹）

## 常见陷阱
- 菜品图片多导致的首屏加载慢
- 购物车中的规格组合（大小 + 冰度 + 甜度 + 加料）
- 菜单分类在移动端的横向滚动导航
- 配送费计算的实时性（距离/时段/满减）
- 食谱步骤中的计时器多任务管理

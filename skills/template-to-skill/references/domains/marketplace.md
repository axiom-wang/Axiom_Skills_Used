# Marketplace（多卖家平台）

## 识别关键词
marketplace, seller, vendor, listing, bid, auction, review, rating, multi-vendor, commission

## 核心骨架
- 商品/服务列表 + 搜索 + 筛选 + 详情
- 卖家店铺/主页
- 评价系统（买家评卖家）
- 多维度排序（价格、评分、销量、距离）

## 典型可定制点

| 可定制点 | 粒度 | 说明 |
|--------|------|------|
| 搜索增强 | 功能模块 | 全文搜索、筛选组合、搜索建议、历史 |
| 卖家系统 | 路由级 | 卖家入驻、商品管理、订单管理、数据面板 |
| 评价体系 | 组件级 | 星级、文字评论、图片评论、追评 |
| 交易模式 | 业务逻辑 | 一口价、竞拍、议价、租赁 |
| 推荐算法 | 功能模块 | 相似商品、猜你喜欢、最近浏览 |
| 地理位置 | 功能模块 | 附近卖家、配送范围、地图展示 |
| 争议处理 | 功能模块 | 退款、仲裁、客服入口 |

## 设计推断侧重
- 商品密度 → 列表布局（高密度网格 vs 大图瀑布流）
- 信任建设 → 卖家信息展示权重（评分/认证/成交量）
- 品类特征 → 筛选维度设计
- 交易频率 → 购买流程长度（高频简化，低频详尽）

## 常见陷阱
- 大量列表的分页/无限滚动性能
- 筛选条件组合爆炸（URL 参数管理）
- 价格显示一致性（含税/不含税/运费）
- 搜索结果为空时的降级展示
- 多图商品的轮播与预加载

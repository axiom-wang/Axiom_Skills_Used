# Jobs（招聘/求职）

## 识别关键词
job, career, hiring, apply, resume, candidate, employer, vacancy, position, salary, remote

## 核心骨架
- 职位列表 + 搜索 + 筛选
- 职位详情页（JD + 公司信息 + 申请按钮）
- 申请流程（简历上传/在线填写 + 提交）
- 公司主页/雇主品牌页

## 典型可定制点

| 可定制点 | 粒度 | 说明 |
|--------|------|------|
| 高级搜索 | 组件级 | 薪资范围、远程/驻场、经验年限、技能标签 |
| 简历构建 | 功能模块 | 在线编辑器、模板选择、PDF 导出 |
| 公司页面 | 路由级 | 公司介绍、团队、福利、在招职位 |
| 申请管理 | 功能模块 | 申请状态跟踪、面试日历 |
| 推荐匹配 | 功能模块 | 智能推荐、职位匹配度评分 |
| 薪资洞察 | 功能模块 | 行业薪资、城市对比 |
| 通知提醒 | 功能模块 | 新职位订阅、申请状态更新 |

## 设计推断侧重
- 平台定位 → 视觉风格（技术类偏简洁深色，综合类偏明亮友好）
- 目标用户 → 信息密度（高管偏精简高端，应届偏引导详尽）
- 行业特征 → 关键筛选维度（技术类重技能栈，金融类重资质）
- 地域特征 → 薪资展示格式（月薪/年薪/K）

## 常见陷阱
- 搜索条件组合的 URL 状态同步
- 职位列表大量数据的性能（虚拟滚动/分页）
- 简历文件上传的格式兼容（PDF/Word/图片）
- 富文本 JD 的安全渲染
- 移动端长表单的分步体验

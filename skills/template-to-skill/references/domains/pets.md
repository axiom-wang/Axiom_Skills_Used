# Pets（宠物相关）

## 识别关键词
pet, dog, cat, breed, adoption, grooming, vet, veterinary, pet-care, pet-food, animal

## 核心骨架
- 宠物/服务展示（品种列表、服务项目）
- 宠物档案（品种信息、护理指南、健康记录）
- 预约/购买入口（美容、寄养、诊疗、商品）
- 社区/分享（晒宠、问答）

## 典型可定制点

| 可定制点 | 粒度 | 说明 |
|--------|------|------|
| 品种百科 | 数据模型 | 品种详情、养护建议、适合人群 |
| 商城功能 | 功能模块 | 宠物食品、用品、处方粮 |
| 预约系统 | 功能模块 | 美容预约、诊疗预约、寄养 |
| 宠物档案 | 数据模型 | 宠物信息、疫苗记录、体重曲线 |
| 社区互动 | 功能模块 | 晒宠、问答、经验分享 |
| 领养系统 | 功能模块 | 领养信息、申请流程、配对 |
| 位置服务 | 功能模块 | 附近宠物医院、宠物公园、遛狗路线 |

## 设计推断侧重
- 宠物类型 → 视觉调性（猫偏温柔圆润，狗偏活泼运动）
- 服务定位 → 配色（高端宠物 SPA 偏素雅，社区偏明亮）
- 目标受众 → 信息密度（专业养殖者详尽，普通宠主简洁）
- 品牌个性 → 插画/图标风格（可爱卡通 vs 简约线条）

## 常见陷阱
- 大量品种图片的加载优化
- 宠物信息表单的字段联动（品种→体型→推荐食量）
- 预约时间与服务人员可用性的实时同步
- 社区内容审核（不当内容过滤）
- 移动端拍照上传的图片压缩

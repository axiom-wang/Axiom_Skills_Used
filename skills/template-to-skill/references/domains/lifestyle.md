# Lifestyle（生活方式品牌）

## 识别关键词
lifestyle, fashion, magazine, trend, collection, editorial, lookbook, seasonal, aesthetic, mood, curated

## 核心骨架
- 视觉驱动的首页（大图 Hero + 编辑推荐 + 分类入口）
- 内容/产品混合展示（编辑文章 + 商品推荐）
- 品牌故事/关于页面
- 社交媒体/社区联动

## 典型可定制点

| 可定制点 | 粒度 | 说明 |
|--------|------|------|
| 内容板块 | 路由级 | 编辑精选、穿搭灵感、生活指南、品牌故事 |
| 商品导购 | 功能模块 | 同款推荐、look 整套购买、外链购买 |
| 会员体系 | 功能模块 | 会员等级、专属内容、早期访问 |
| 季节性内容 | 业务逻辑 | 季度 collection、节日专题、限时活动 |
| 社交分享 | 组件级 | Pinterest 式瀑布流、Instagram embed、UGC |
| 个性化推荐 | 功能模块 | 风格测试、偏好设定、个性化 feed |
| 多媒体内容 | 组件级 | 视频 lookbook、播客、交互式 editorial |

## 设计推断侧重
- 品牌调性 → 全站视觉基调（极简高冷 vs 复古温暖 vs 先锋大胆）
- 内容形式 → 排版（图片为主用大留白，文字为主用杂志排版）
- 目标受众 → 配色和字体（年轻女性偏柔和衬线，潮流偏粗体无衬线）
- 季节感 → 首页视觉更新频率和方式

## 常见陷阱
- 大量高质量图片的加载策略（渐进式 JPEG、art direction）
- 瀑布流布局的移动端适配
- 视觉优先导致的可访问性问题（对比度、alt text）
- 季节性内容切换时的缓存更新
- 字体加载闪烁（FOUT/FOIT 处理）

# Service（企业服务/SaaS 落地页）

## 识别关键词
service, pricing, plan, feature, demo, signup, contact, enterprise, solution, integration, API

## 核心骨架
- 单页或少页结构（Hero → Features → Pricing → Testimonials → CTA）
- 定价方案对比表
- 表单收集（联系/注册/预约 demo）
- 客户 logo 墙 / 案例展示

## 典型可定制点

| 可定制点 | 粒度 | 说明 |
|--------|------|------|
| 新增 section | 页面级 | FAQ、团队介绍、集成列表、博客摘要 |
| 定价方案 | 数据模型 | 月/年切换、多层定价、自定义方案、企业询价 |
| 表单字段 | 组件级 | 公司名、职位、团队规模、需求描述 |
| 多语言版本 | 全局配置 | 中英文切换 |
| 集成第三方 | 功能模块 | Analytics、Intercom、HubSpot、Calendar embed |
| 动画效果 | 视觉层 | 滚动触发、入场动画、数据计数器 |
| A/B 变体 | 全局 | 不同 Hero 文案、不同 CTA 按钮 |

## 设计推断侧重
- 产品类型 → 视觉风格（B2B 偏专业克制，B2C 偏活泼大胆）
- 目标行动 → CTA 按钮设计（注册/购买/预约差异大）
- 价格段 → 页面质感（高客单价需要更精致）
- 竞品定位 → 差异化视觉策略

## 常见陷阱
- 移动端响应式断点处理（定价表在小屏的展示）
- 首屏加载速度（大图/视频优化）
- 表单验证 UX（实时 vs 提交时）
- SEO meta tags 完整性
- 定价方案切换时的动画卡顿

# Store（品牌电商）

## 识别关键词
product, cart, checkout, order, catalog, wishlist, price, SKU, inventory, shop, buy, add-to-cart

## 核心骨架
- 商品列表 + 详情 + 购物车 三页面结构
- CartContext / 购物车状态管理
- 商品数据模型（id, name, price, image, variants）
- 分类/筛选体系

## 典型可定制点

| 可定制点 | 粒度 | 说明 |
|--------|------|------|
| 新增页面 | 路由级 | 收藏夹、订单历史、用户中心、搜索结果页 |
| 商品字段扩展 | 数据模型 | materials, origin, weight, reviews, rating |
| 筛选维度增减 | 组件级 | 价格区间、颜色、尺码、品牌、评分 |
| 支付方式 | 功能模块 | 信用卡、PayPal、Apple Pay、货到付款 |
| 多货币/多语言 | 全局配置 | i18n、货币切换、汇率 |
| 促销机制 | 业务逻辑 | 折扣码、满减、限时特价、捆绑销售 |
| 商品变体 | 数据模型 | 颜色×尺码 组合、库存联动 |
| 用户系统 | 功能模块 | 注册登录、地址簿、订单跟踪 |

## 设计推断侧重
- 品牌定位 → 配色/排版/间距（越高端越多留白）
- 商品类型 → 图片比例（服装偏竖、电子偏方）
- 价位段 → 页面留白量（越贵越多留白）
- 受众性别 → 是否显示性别筛选
- 语言/地区 → 货币符号和价格格式

## 常见陷阱
- 购物车状态丢失（Context re-render 导致数量重置）
- 颜色/尺码组合的库存联动
- 价格格式化（千分位、货币符号位置）
- 图片懒加载与占位符闪烁
- 结账流程中的表单状态管理

# Portfolio（个人作品集）

## 识别关键词
portfolio, project, showcase, gallery, resume, CV, work, case-study, about-me, contact

## 核心骨架
- Hero/自我介绍 + 作品网格/列表
- 项目详情页（图片/视频 + 描述 + 技术栈）
- 关于我 + 技能展示
- 联系方式/表单

## 典型可定制点

| 可定制点 | 粒度 | 说明 |
|--------|------|------|
| 作品分类 | 组件级 | 标签筛选、类型切换（设计/开发/写作） |
| 交互动效 | 视觉层 | 页面转场、滚动动画、鼠标跟随、3D 效果 |
| 博客/文章 | 路由级 | 技术文章、设计笔记 |
| 时间线 | 组件级 | 工作经历、教育背景、里程碑 |
| 暗色模式 | 全局配置 | 主题切换 |
| 下载简历 | 功能模块 | PDF 生成、多语言版本 |
| 客户评价 | 组件级 | 推荐信、评分、合作品牌 |

## 设计推断侧重
- 职业方向 → 视觉风格（设计师偏创意大胆，开发者偏简洁技术感）
- 作品类型 → 展示布局（摄影大图 masonry，UI 设计规整网格，代码项目列表式）
- 个人品牌 → 配色（独特但不喧宾夺主）
- 受众 → 信息优先级（HR 看经历，客户看案例）

## 常见陷阱
- 大图/视频的加载性能与占位处理
- 过度动画导致的可访问性问题（prefers-reduced-motion）
- 响应式图片网格的断点处理
- 联系表单的垃圾信息防护
- 项目详情页的 SEO（动态路由需要 meta tags）

# Digital Goods（数字产品销售）

## 识别关键词
digital, template, plugin, theme, asset, download, license, preset, font, icon, mockup, resource

## 核心骨架
- 产品展示（预览 + 描述 + 技术规格）
- 分类/搜索/筛选
- 购买/下载流程（即时交付）
- 预览/试用功能

## 典型可定制点

| 可定制点 | 粒度 | 说明 |
|--------|------|------|
| 预览方式 | 组件级 | 实时 demo、截图画廊、视频预览、代码预览 |
| 授权模式 | 数据模型 | 个人/商业/团队授权、按站点/按项目 |
| 版本管理 | 功能模块 | 更新日志、历史版本下载、兼容性说明 |
| 捆绑销售 | 业务逻辑 | 套装包、订阅制、会员下载 |
| 用户评价 | 组件级 | 评分、使用反馈、展示案例 |
| 创作者系统 | 路由级 | 创作者主页、收益面板、上传管理 |
| 兼容性标注 | 数据模型 | 软件版本、文件格式、分辨率 |

## 设计推断侧重
- 产品类型 → 预览方式（模板重实时 demo，字体重排版预览，图标重网格展示）
- 受众专业度 → 技术细节暴露（开发者看代码/API，设计师看视觉预览）
- 价格策略 → 页面设计（免费为主重量，付费为主重质感）
- 品牌定位 → 配色（设计资源偏高端简洁，开发工具偏技术深色）

## 常见陷阱
- 实时预览的沙箱安全（iframe 隔离）
- 大文件下载的稳定性（断点续传）
- 授权验证流程的用户体验
- 产品截图多时的加载策略
- 搜索结果中的文件格式/兼容性筛选复杂度

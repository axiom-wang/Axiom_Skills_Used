# Game（游戏相关）

## 识别关键词
game, player, score, level, leaderboard, achievement, character, quest, inventory, PvP, guild

## 核心骨架
- 游戏主页/官网（Hero + 特性介绍 + 预告）
- 或 H5 游戏界面（画布 + UI overlay + 控制面板）
- 排行榜 / 成就系统
- 角色/装备展示

## 典型可定制点

| 可定制点 | 粒度 | 说明 |
|--------|------|------|
| 社区功能 | 路由级 | 论坛、攻略、玩家分享 |
| 商城系统 | 功能模块 | 虚拟道具购买、充值、兑换码 |
| 排行榜 | 组件级 | 多维排行、赛季、好友排行 |
| 成就/徽章 | 数据模型 | 成就树、进度追踪、解锁动画 |
| 活动系统 | 功能模块 | 限时活动、签到、每日任务 |
| 社交功能 | 功能模块 | 好友、公会、聊天、组队 |
| 数据统计 | 功能模块 | 战绩、胜率、历史对局 |

## 设计推断侧重
- 游戏类型 → 视觉风格（RPG 偏奇幻深色，休闲偏明亮卡通）
- 目标平台 → 布局（PC 宽屏，移动端竖屏优先）
- 受众年龄 → 色彩饱和度和字号
- 品牌调性 → 动画密度（硬核克制，休闲活泼）

## 常见陷阱
- Canvas/WebGL 与 React DOM 的混合渲染
- 排行榜大数据量的虚拟滚动
- 实时数据更新（WebSocket 重连策略）
- 游戏资源预加载的进度反馈
- 移动端触摸事件与 UI 交互冲突

# Course（在线教育）

## 识别关键词
course, lesson, quiz, progress, enrollment, certificate, instructor, student, learning, module, curriculum

## 核心骨架
- 课程列表/分类 + 课程详情
- 学习播放页（视频/文档 + 侧边目录）
- 进度追踪系统
- 证书/完课结果

## 典型可定制点

| 可定制点 | 粒度 | 说明 |
|--------|------|------|
| 内容格式 | 组件级 | 视频、文档、互动练习、代码沙箱、音频 |
| 评估方式 | 功能模块 | 选择题、编程题、作业提交、同伴评审 |
| 学习路径 | 业务逻辑 | 前置课程依赖、推荐路径、学习计划 |
| 证书系统 | 功能模块 | 完课证书、技能认证、可分享证书 |
| 讨论区 | 功能模块 | 课程问答、笔记分享、学习小组 |
| 直播课 | 功能模块 | 实时互动、白板、录播回放 |
| 学习数据 | 数据模型 | 时长统计、正确率、学习曲线、streak |

## 设计推断侧重
- 内容形式 → 播放器布局（视频为主 vs 文档为主 vs 互动为主）
- 受众年龄 → 视觉风格（K12 偏活泼彩色，职业教育偏专业克制）
- 学习模式 → 进度展示方式（线性 vs 自由浏览）
- 平台规模 → 首页设计（单课程聚焦 vs 多课程发现）

## 常见陷阱
- 视频播放的跨浏览器兼容（HLS）
- 进度断点保存的精度（秒级 vs 章节级）
- 测验防作弊（计时、切屏检测的前端限制）
- 大文件上传的稳定性（作业/视频）
- 课程目录的深层嵌套展示

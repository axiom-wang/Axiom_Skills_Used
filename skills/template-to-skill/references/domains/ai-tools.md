# AI Tools（AI 产品界面）

## 识别关键词
AI, chat, prompt, generate, model, completion, GPT, assistant, conversation, input-output, stream

## 核心骨架
- 输入区（prompt/上传）+ 输出展示区
- 对话历史或生成历史
- 模型/参数选择面板
- 流式输出展示

## 典型可定制点

| 可定制点 | 粒度 | 说明 |
|--------|------|------|
| 输入模式 | 组件级 | 文本、图片上传、语音、文件拖拽 |
| 输出格式 | 组件级 | Markdown 渲染、代码高亮、图片画廊、表格 |
| 历史管理 | 功能模块 | 对话列表、收藏、搜索、导出 |
| 模型切换 | 数据模型 | 多模型选择、参数调节（temperature 等） |
| 模板/Prompt 库 | 功能模块 | 预设 prompt、分类、社区分享 |
| 用量/计费 | 功能模块 | token 计数、额度展示、升级提示 |
| 插件/工具调用 | 功能模块 | 联网搜索、代码执行、文件解析 |

## 设计推断侧重
- 交互模式 → 布局（对话式偏聊天 UI，工具式偏左右分栏）
- 输出类型 → 展示区设计（纯文本 vs 富媒体）
- 用户技术水平 → 参数暴露程度（小白隐藏参数，开发者全暴露）
- 产品调性 → 配色（专业工具偏深色，消费级偏浅色活泼）

## 常见陷阱
- 流式输出的逐字渲染性能（大段文本需要虚拟化）
- Markdown 渲染中的 XSS 防御
- 长对话的内存管理（历史消息过多）
- 输入框的自动高度调整与最大高度限制
- 网络中断后的重试和断点续传

# Finance（金融/理财）

## 识别关键词
finance, invest, crypto, wallet, portfolio, stock, trading, budget, expense, payment, bank, fund

## 核心骨架
- 资产概览仪表盘（总资产、收益曲线、持仓分布）
- 交易/操作界面（买入/卖出/转账）
- 记录/流水列表
- 市场行情/资讯

## 典型可定制点

| 可定制点 | 粒度 | 说明 |
|--------|------|------|
| 图表类型 | 组件级 | K 线图、收益曲线、饼图分布、对比图 |
| 资产类型 | 数据模型 | 股票、基金、加密货币、外汇、储蓄 |
| 交易功能 | 功能模块 | 限价单、市价单、止盈止损、定投 |
| 记账功能 | 功能模块 | 收支分类、预算设定、账单导入 |
| 行情推送 | 功能模块 | 实时报价、价格提醒、新闻快讯 |
| 分析报告 | 功能模块 | 月度总结、税务报告、收益分析 |
| 安全验证 | 功能模块 | 二次验证、交易密码、设备管理 |

## 设计推断侧重
- 产品类型 → 配色（银行偏稳重蓝灰，加密偏暗黑荧光，记账偏清新）
- 数据精度 → 数字展示格式（小数位、千分位、正负色）
- 用户专业度 → 界面复杂度（小白偏简化，专业偏密集数据）
- 风险等级 → 警示色使用频率（高风险产品多用红/黄提示）

## 常见陷阱
- 金额的精度处理（浮点数误差，用整数分计算）
- 实时数据的更新频率与性能平衡
- 大量数字的可读性（千分位、缩写、颜色编码）
- 金融图表的移动端触摸交互
- 安全敏感操作的确认流程 UX

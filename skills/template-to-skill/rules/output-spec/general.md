# 产出 SKILL 的通用规范

## 命名规范

- SKILL 目录：`<模版名>_skill/`（小写下划线）
- Task 文件：`NN-动词.md`（如 `01-generate-code.md`）
- 案例文件：`kebab-case.md`（如 `streetwear.md`）
- 规则文件：`kebab-case.md`

## 提炼原则

从对话历史/源码中提炼产品定义时：

| 做 | 不做 |
|---|-----|
| 从最终源码提取功能清单 | 逐轮记录对话过程 |
| 从 Tailwind 类名总结视觉风格 | 照抄用户原话当"需求" |
| 归纳用户画像 | 把对话顺序当功能优先级 |
